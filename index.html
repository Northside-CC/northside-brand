Northside Brand Kit

This repository is the single source of truth for Northside Christian Church's brand assets, colors, typography, and voice. It is built so staff, volunteers, and AI tools can all produce work that looks and sounds like Northside.

Agent instructions

Start with brand-kit.json. It holds all structured brand data in one machine-readable file. For voice, naming, logo usage, and writing rules, read brand-guidelines.md. All asset paths in the JSON are relative to the repo root. When producing branded output, use Green NCC (#0E8291) as the lead color, write Northside Christian Church on first reference (never "Northside Church"), and follow the voice object. Logo files are SVGs in logos/. Prefer the full logo in most contexts. Fields marked needs_review are not confirmed yet, so check with the Digital Ministry team before relying on them.

JSON Schema

What each top-level key holds.

KeyDescription
brandChurch name, mission ("Connecting People to Jesus"), location, website, and brand architecture (branded house).
namingHow to write our name, plus approved abbreviations (VAN, NSM, YA).
colors.primaryGreen NCC (#0E8291), the main brand color. Includes RGB, CMYK, Pantone, and a text_on value.
colors.paletteYellow NCC, Dark Coral, Light Purple, Cream, and Light Brown. Each with RGB, CMYK, Pantone, and text_on.
colors.web_neutralsSix-step neutral scale used on mynorthside.com, from #1D1D1D to white.
colors.semanticSuccess, info, warning, and danger colors used on mynorthside.com.
typographyGotham, Dharma Gothic, and Helvetica Neue / Now with roles, weights, CSS fallback stacks, and type rules. Font files are licensed and not included.
logosPaths for full_logo and logo_mark in light and dark variants. Includes the clear space rule, minimum size, and don'ts.
sub_brandsThe branded-house rule and its two exceptions, Kidside and NSM.
brand_elementsNorthside Waves, noise, photo containers, and textures, each with usage guidance.
photographyShooting and editing guidance.
voiceVoice summary, audience, tone words, things to avoid, and Scripture quoting rules.
usageDos and don'ts for applying the brand.
