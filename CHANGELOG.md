# Changelog

Each version matches the `version` field in `brand-kit.json`.

## 0.3.0 (2026-11-12)

Resolved open review items with the Digital Ministry team and added brand elements from the NCC branding package.

**Added**

- Gradients 1 to 5, Northside Waves, and paper texture in `brand-elements/` (web-sized exports).
- Gradient colors (six hex values sampled from the gradient files), for gradients only.
- Proxima Nova as the approved web typeface.
- Minimum sizes for the simple logo (0.75 in) and logo mark (0.375 in).
- Alt text guidance in `logos.alt_text`.
- Naming rules for Northside Young Adults and the Kidside spelling.
- Planned file paths for the missing YA logos (`logos_planned`).
- This changelog.

**Changed**

- Dark Coral Pantone set to 18-649 TCX (textile code, noted as such).
- Sea Kidside `#59BFD1` confirmed.
- Gotham Black added to the main Gotham weights.
- The Digital Ministry team is now the single approver for partial logo use, for Northside and all sub-brands.
- Logo source wording now says some sub-brand logos are PNG only.
- GitHub Repo and Download ZIP links now have real URLs in the HTML.
- Brand Review page shows the gradients and handles typefaces without listed weights.

**Removed**

- Duplicate first-reference naming rule from `usage.do`.

**Still open**

- Sea Kidside and Green 1 CMYK values.
- YA horizontal, stacked, and logo mark files.
- SVG versions of NSM and YA logos.
- A Pantone C equivalent for Dark Coral.
